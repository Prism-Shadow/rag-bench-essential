# Data

This payload contains one scanned document image from a public DocVQA
single-page question mirror.

- Source family: DocVQA, document visual question answering over scanned
  document images.
- Visible file: `document_page.jpg`.
- Format: grayscale JPEG document image, 1692 x 2245 pixels.
- Document type: scanned retail partner contract/tax form page.

The case is intentionally image-first. No OCR text file is provided. The answer
is in a handwritten field near a printed field label, so blind OCR can produce a
plausible but wrong date.
