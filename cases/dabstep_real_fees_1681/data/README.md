# Data files

- `payments.csv`: synthetic payment transactions; column definitions are in `payments-readme.md`.
- `fees.json`: fee rules used by the task.
- `merchant_data.json`: merchant attributes.
- `acquirer_countries.csv`: acquiring-country reference data.
- `merchant_category_codes.csv`: merchant category code reference data.
- `manual.md`: task-specific data interpretation notes.

These files form the complete Agent-visible payload for this case.
