# Data

This directory contains the agent-visible source packet for a Harvey LAB
corporate M&A diligence task. The packet is a synthetic but practice-shaped
transaction file set covering draft SPA representations, disclosure schedules,
and buyer diligence support.

## Files

All source documents are under `documents/`.

| File | Type | Role |
| --- | --- | --- |
| `draft-spa-reps-warranties.docx` | Word | Draft SPA representations and warranties. |
| `disclosure-schedules-seller-draft.docx` | Word | Seller draft disclosure schedules. |
| `diligence-report-summary.docx` | Word | Buyer-side diligence report summary. |
| `ip-diligence-memo.docx` | Word | IP diligence support. |
| `key-contract-summary.xlsx` | Excel | Contract diligence support. |
| `ebitda-bridge-workpaper.xlsx` | Excel | EBITDA adjustment support. |
| `ridgeline-diligence-email.eml` | Email | Supplemental diligence email. |

## Scale

The packet contains 7 files totaling about 272 KB. The task is not a single-file
lookup: the discrepancies depend on comparing legal representations and
disclosure schedules against multiple diligence sources.

## Caution

The documents contain overlapping legal, financial, IP, environmental,
employment, tax, and contract references. Similar terms can appear in both the
SPA/disclosure materials and the diligence support, so each finding should bind
the representation or schedule to the conflicting diligence source.
