# Artifact Rubric — MultiHiertt Global Products ATOI share change

Only the final numeric value in `answers.json` is scored. A scalar or
single-element list, encoded as a number or numeric string, is accepted.

The value must match the full-precision gold within an absolute tolerance of
`0.000005`, which corresponds to rounding the benchmark answer to five decimal
places. Document retrieval, source ids, evidence, formula narration,
intermediate values, trace content, and extra files do not affect the score.
