# Artifact Rubric

Only `answers.json` is scored. Its `answer` value must match the accepted
architecture-firm name after normalization. The search strategy, cited sources,
constraint checklist, trace, intermediate candidates, and extra files do not
affect the score.

This case is binary: correct firm name is PASS; a missing, malformed, or wrong
answer is FAIL. Corpus-search behavior may still be inspected separately for
research diagnosis, but never changes the official result.
