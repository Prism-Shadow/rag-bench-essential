# Data

This folder contains SEC 10-K markdown reports and a document manifest.

- `document_manifest.csv`: ticker-level manifest for the report set.
- `reports/`: markdown-rendered 10-K reports. File names follow `<TICKER>_<YEAR>_10K.md`.

For this task, use only the report files named `*_2024_10K.md`. The other years are present to preserve the original multi-year corpus shape.
