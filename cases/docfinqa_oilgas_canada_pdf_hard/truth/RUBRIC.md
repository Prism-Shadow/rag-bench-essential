# Artifact Rubric - DocFinQA Devon Annual Report PDF

Only the final value in `answers.json` is scored. The normalized value must be
`24.69` within a tolerance of 0.02 percentage points. A numeric value or string,
with or without `%`, is accepted.

The decimal fraction `0.2469` without a percent sign is not automatically
rescaled. PDF navigation, page selection, calculation fields, evidence,
intermediate values, trace content, and extra files do not affect the score.
